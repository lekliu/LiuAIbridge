# LiuAIbridge 部署指南

> 本文档介绍如何从零开始部署一个基于 Cloudflare Workers 的 AI API 网关。部署完成后，国内可直接访问 OpenAI、Gemini、Claude 等海外大模型 API，无需客户端配置网络代理。

---

## 核心价值

| 特性 | 说明 |
|------|------|
| **网络直连** | 基于 Cloudflare 全球边缘网络，国内直接访问海外 API |
| **无客户端配置** | 部署后客户端无需任何网络代理即可调用 |
| **多模型兼容** | 支持 OpenAI、Google Gemini、Anthropic Claude |
| **密钥统一管理** | 可视化后台管理多组 API Key，自动轮询 |

| 必备项 | 说明 | 获取方式 |

## 步骤 1: 安装 wrangler 命令行工具

wrangler 是 Cloudflare Workers 的官方命令行工具。

安装命令：

```bash
npm install -g wrangler
```

安装完成后，登录 Cloudflare 账号：

```bash
wrangler login
```

浏览器将自动打开授权页面，点击授权即可完成登录。

---

## 步骤 2: 创建 KV 命名空间

Cloudflare KV 是一个全局键值存储，用于存储配置和密钥。

执行以下命令创建 KV 命名空间：

```bash
wrangler kv namespace create LIU_BRIDGE_KV
```

执行成功后，你将看到类似以下输出：

```json
{
  "id": "abc123def456ghi789jkl012mno345",
  "title": "LIU_BRIDGE_KV"
}
```

请记录返回的 `id` 值，后续配置需要使用。

---

## 步骤 3: 配置 wrangler.toml

打开项目根目录的 `wrangler.toml` 配置文件，填入上一步获取的 KV 命名空间 ID：

```toml
name = "liu-aibridge"
compatibility_date = "2024-01-01"

kv_namespaces = [
  { binding = "LIU_BRIDGE_KV", id = "此处填入你刚才记录的 id" }
]
```

保存配置文件。

---

## 步骤 4: 设置 Secrets

配置环境变量，包括管理后台和 API 调用的安全令牌。

```bash
# 设置管理员令牌（用于登录管理后台）
wrangler secret put ADMIN_TOKEN

# 设置桥接令牌（用于 API 调用鉴权）
wrangler secret put BRIDGE_TOKEN
```

执行每条命令后，在提示符后输入对应的值。

安全建议：
- 两个 Token 应设置为不同的值
- 建议长度不少于 16 位，包含大小写字母和数字
- BRIDGE_TOKEN 将用于客户端代码，请注意保密

---

## 步骤 5: 部署到 Cloudflare

执行部署命令：

```bash
wrangler deploy
```

成功部署后，你将看到类似以下输出：

```
Total Upload: 50.12 KiB / gzip: 12.34 KiB
Uploaded liu-aibridge (1.23 sec)
Published liu-aibridge (0.45 sec)
  https://liu-aibridge.yourname.workers.dev
```

记录返回的访问地址，后续步骤需要使用。

---

- 查看最后活跃时间

## 步骤 8: 功能验证

部署完成后，建议进行以下验证确保服务正常运行：

### 验证方式一：curl 命令

```bash
# 测试 OpenAI 原生接口
curl -X POST "https://你的域名/openai/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的BRIDGE_TOKEN" \
  -d '{"model":"gpt-3.5-turbo","messages":[{"role":"user","content":"你好"}]}'
```

```bash
# 测试 Gemini OpenAI 兼容格式
curl -X POST "https://你的域名/compat/openai/google/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的BRIDGE_TOKEN" \
  -d '{"model":"gemini-1.5-flash","messages":[{"role":"user","content":"你好"}]}'
```

### 验证方式二：Python SDK

```python
from openai import OpenAI

# 初始化客户端，base_url 为网关地址
client = OpenAI(
    base_url="https://你的域名/compat/openai/google/v1",
    api_key="你的BRIDGE_TOKEN"
)

# 调用 Gemini 模型
response = client.chat.completions.create(
    model="gemini-1.5-flash",
    messages=[{"role": "user", "content": "你好，请介绍一下你自己"}],
    stream=True
)

# 流式输出
for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```

如果收到正常响应，说明部署成功。

## 常见问题

### Q: 部署失败如何排查？
A: 建议检查以下几点：
- `wrangler.toml` 中的 kv id 是否正确
- Cloudflare 账号邮箱是否已验证
- 网络是否能正常访问 Cloudflare

### Q: API 请求返回 401 Unauthorized？
A: 检查请求头中 `Authorization` 或 `X-Bridge-Token` 的值是否与设置的 `BRIDGE_TOKEN` 一致

### Q: 是否支持配置多个 API Key？
A: 支持。每个服务商可以添加多个密钥，系统将基于全局请求计数进行轮询负载均衡

### Q: 如何更新代码？
A: 修改代码后重新执行 `wrangler deploy` 即可，配置变更通常在 10 秒内全球生效
